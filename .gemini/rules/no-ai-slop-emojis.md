# Rule: Zero AI-Slop Emojis Policy

## 1. Absolute Prohibition of Decorative Emojis
- Never use decorative, AI-slop, or ornamental emojis in any source code, comments, commit messages, documentation, user interfaces, chat responses, or generated artifacts.
- Prohibited patterns include, but are not limited to:
  - Rocket, Launch: 🚀
  - Lightbulb, Idea: 💡
  - Sparkles, Magic, Stars: ✨, ⭐, 🌟
  - Checkmarks & Crosses: ✅, ❌, ✔️, ❎ (use standard markdown `[x]`, `[ ]`, or plain text "PASS" / "FAIL")
  - Warning & Alert: ⚠️, 🚨, 🛑 (use GitHub-style markdown alerts `> [!WARNING]`, `> [!IMPORTANT]`, or plain text "[WARN]", "[ERROR]")
  - Tools & Construction: 🛠️, 🔧, 🔨, 🏗️
  - Celebration: 🎉, 🥳, 🎊
  - Robot, AI, Brain: 🤖, 🧠
  - Video & Cameras: 📹, 🎥, 📷, 🎬
  - Writing & Stationery: ✏️, 📝, 📌, 📍
  - Shields & Badges: 🛡️, 🔰, 🏆, 🎖️
  - Hand Gestures: 👋, 👍, 👎, 🤝, 🙌
  - Communication: 💬, 📢, 🔔, ✉️
  - Clocks & Time: ⏰, ⏳, ⌛
  - Arrows: 👉, 👈, 👆, 👇, ➡️ (use standard ASCII `->`, `<-`, `=>`)

## 2. Professional Academic & Engineering Standards
- Use clean, unambiguous plain text, standard Markdown formatting, GitHub-style callouts (`> [!NOTE]`, `> [!IMPORTANT]`), tables, and code blocks.
- In UI code: Always use vector icon libraries (such as `lucide-react`) rather than raw emoji characters.
- In documentation, reports, and code comments: Maintain a rigorous, professional academic tone free from generic AI tropes.
