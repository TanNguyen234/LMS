## Severity count and remaining product limits

- Confirmed at baseline: **4 P0, 8 P1, 1 P2**.
- Current confirmed open P0/P1 within the documented MVP: **0**. Verification is backed by 44 SQL Server tests, 51 live OpenAPI operations, HTTP health and the final Chrome E2E.
- “Delete” in current product flows is reversible lifecycle behavior: user deactivate/reactivate, course archive/reactivate, enrollment drop/re-enroll, module/lesson unpublish, assignment close/reopen and quiz unpublish/republish. There is no physical-delete route for users, courses, modules, lessons, assignments, quizzes or questions; E2E does not claim one.
- File attachments are not implemented in this MVP. Formal coursework UAT sign-offs remain simulated labels; the technical browser acceptance was executed separately and does not turn those into real approvals.
- Lint exits successfully with 15 nonblocking existing style/hooks warnings. No external deployment or uptime claim is made.
