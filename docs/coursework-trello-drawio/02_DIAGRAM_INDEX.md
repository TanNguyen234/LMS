# Danh sách sơ đồ editable cho draw.io

Dùng **File → Open From → Device** trong https://app.diagrams.net/ để mở file `.drawio`, rồi chỉnh sửa và lưu lại.

| File | Nội dung | Ghi chú |
|---|---|---|
| [01_project_workflow.drawio](diagrams/01_project_workflow.drawio) | Dòng công việc quản lý dự án | Minh họa các phase, không phải lịch hay trạng thái thực tế |
| [02_lms_use_cases.drawio](diagrams/02_lms_use_cases.drawio) | Tương tác 3 vai trò với LMS | Phạm vi nghiệp vụ gợi ý, cần xác nhận nhóm |
| [03_lms_architecture.drawio](diagrams/03_lms_architecture.drawio) | Kiến trúc React — FastAPI — SQL Server | Phản ánh công nghệ hiện hữu trong repo |

Để vẽ thêm **ERD** và **Activity Diagram**, có thể dựa vào `docs/04_DATABASE_DESIGN.md` và `docs/07_BUSINESS_RULES.md`; các loại sơ đồ này không được cô xác nhận là bắt buộc.

**Quan trọng:** Những sơ đồ này là bản **khởi tạo có thể chỉnh sửa**, chưa được reviewer/giảng viên nghiệm thu. Khi chỉnh sửa, liên kết bản mới với thẻ Trello tương ứng.
