# Bộ khởi động đồ án: Trello và draw.io

**Tên đề tài cô giao:** Quản lý dự án xây dựng hệ thống quản lý học tập trực tuyến (LMS) cho trường đại học.

**Hai công cụ được cô nêu:** Trello để quản lý dự án; draw.io/diagrams.net để vẽ sơ đồ.

## Cách bắt đầu đúng hướng

1. Tạo **một Trello Board** theo [kế hoạch Trello](01_TRELLO_BOARD_PLAN.md), phân công thành viên thật và gắn checklist/evidence.
2. Mở các file `.drawio` trong thư mục này bằng https://app.diagrams.net/ để chỉnh theo phạm vi thật:
   - [Quy trình thực hiện dự án](diagrams/01_project_workflow.drawio)
   - [Use case LMS](diagrams/02_lms_use_cases.drawio)
   - [Kiến trúc minh họa LMS](diagrams/03_lms_architecture.drawio)
3. Gắn liên kết file draw.io, commit, hình xuất PNG/PDF hoặc ảnh Trello vào thẻ tương ứng.
4. Chỉ chọn nội dung LMS phải hiện thực hóa sau khi xác nhận tiêu chí đồ án. Nếu cô chỉ chấm **quản lý dự án trên Trello và sơ đồ draw.io**, code LMS chỉ là phần mở rộng tự nguyện.

## Những việc cần xác nhận với cô khi có cơ hội

- Có bắt buộc lập trình hệ thống LMS chạy thực tế hay chỉ thiết kế & quản lý dự án?
- Cần các loại sơ đồ cụ thể nào: Use Case, Activity, ERD, kiến trúc, WBS, Gantt?
- Cần nộp link Trello, file .drawio, báo cáo Word/PDF, slide và demo ở mức nào?
- Thời hạn, quy mô nhóm, tiêu chí đánh giá và mẫu báo cáo (nếu có)?

**Lưu ý:** Không tạo tình trạng Trello đã làm xong, chữ ký giảng viên, ngân sách/tiến độ thực tế, link board chưa tồn tại hoặc kết quả test giả.
